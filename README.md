# Job Analytics Tool

A Python-based Job Analytics Tool developed during my internship.

## Features
- Data Cleaning and Preprocessing
- Salary Analysis
- Job Category Analysis
- Location-wise Analysis
- Data Visualization using Matplotlib & Seaborn
- CLI-based User Interface

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations
- Salary Distribution
- Jobs per Category
- Jobs per Location
- Experience vs Salary
- Jobs Posted per Month
